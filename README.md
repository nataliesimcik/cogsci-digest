# Cognitive Science Weekly

A weekly digest of new papers and preprints in cognitive psychology and cognitive
science, plus upcoming conference deadlines.

**Site:** https://nataliesimcik.github.io/cogsci-digest/

## Using the site

- Click a topic in the colored bar or the labels below it to filter papers. Click
  more than one to combine them.
- Search titles, authors and summaries, or tick "Top picks only".
- Pick an earlier week from the menu in the top right.
- Deadlines are on the right. Filter by Europe, North America or Online.
  Always confirm dates on the conference's own site.
- To share a filtered view, copy the address bar, e.g. `…/#topics=memory,vision`.

New digests appear every Monday. To follow in Slack or a feed reader, use
`https://nataliesimcik.github.io/cogsci-digest/feed.xml`

## Suggesting papers and changes

- **A paper:** open "All screened papers" at the bottom of the site and click "Suggest"
  next to a paper, or use "Suggest a paper" for anything else. Suggested papers are
  added in the next Monday update, and you get a reply on GitHub with the link.
  You need a free GitHub account to suggest.
- **A conference:** use "Suggest a conference" on the site, or edit `conferences.yaml`.
- **A journal, topic or change in focus:** open an issue, or edit `config.yaml`.

## Sources

Journals via Crossref (including Elsevier, APA, Springer, Wiley and SAGE titles),
arXiv, PsyArXiv and bioRxiv. The full journal list is in `config.yaml`.
